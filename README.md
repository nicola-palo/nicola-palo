## 🔭 About me

Software engineer building **backend services and the data and AI systems around them**. I choose the language for the job: **Java/Spring Boot** for structured business services, **Python** for data and ML pipelines, **Rust** when low latency matters.

My projects focus on the fundamentals: clear service boundaries, one database per service, stateless APIs, token-based authentication and deployment, with AI components (LLMs, computer vision) integrated as regular backend services.
